Lantern Thief — a top-down stealth game: steal the relics from a night museum, dodge the guards' vision cones, hide in the shadows, and reach the exit unseen. Three floors, patrol routes you can learn, a detection system that gives you a chance to recover, and a pebble to lure guards away.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, plain static files.
